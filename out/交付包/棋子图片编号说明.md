# 棋子长什么样 · 只有一种画法

> 你之前问「棋子图片编号怎么填」。
> **结论：图片编号不用填，也填不了。** 这条路在千星奇域上走不通，原因见下。
> 棋子现在只有一种画法：用官方**基础图元**拼出 cburnett（en-croissant 用的那套）风格。
>
> **v1.3 变更**：圆盘档、符号档已按你的要求删除，不再使用 Unicode 棋符。

---

## 一、为什么不用填图片编号

千星奇域的**图片控件不能上传自定义图片**。它只支持两种图片来源：

| 来源 | 说明 |
|---|---|
| `StaticReference`（静态引用） | **官方预设素材，固定白名单**。编号写死在一份白名单里，只能从里面挑 |
| `Prefab`（元件） | 编辑器里自己建的元件图标 |

我把官方白名单的 **1517 个素材全部下载下来逐个看过**：全是 UI 图标（箭头、勾、星、心、盾、剑、药瓶、音符、宝箱、边框、花纹、罗马数字、蛋、卷轴、法杖……），**没有任何一个国际象棋棋子**。

我还按名字搜过 `chess` / `pawn` / `knight` / `rook` / `bishop` / `queen` / `king` / `棋`，全部 0 命中。

平台里唯一能上传图片的地方是「**自定义小地图**」（月之七新增，16×16~2048×2048 px），但那**只能给小地图控件用**，普通图片控件用不上。

所以：**不是我找不到编号，是这个平台上不存在棋子图片可用。**

---

## 二、那棋子现在是怎么画的

用**官方预设的三种基础图元**拼出来，完全不需要你配任何素材：

| 图元 | 编号 | 能干什么 |
|---|---|---|
| 实心矩形 | `100001` | 可染色、可拉伸、可旋转 |
| 实心圆 | `100002` | 可染色、可拉成椭圆 |
| 实心三角 | `100003` | 可染色、可旋转 |

这三个编号**写死在脚本里了**（`CONFIG.PIECE_ASSET`），你不用填、也改不了，开箱即用。

### 每枚棋子怎么拼的

```
兵 = 矩形(底座) + 矩形(身) + 三角(腰) + 矩形(颈) + 圆(头)
车 = 矩形 ×8（底座 / 颈 / 身 / 颈环 / 冠带 / 三个垛口）
马 = 矩形(底座) + 矩形(颈) + 旋转矩形(粗颈) + 旋转矩形(斜脸)
     + 三角(口鼻) + 圆(头顶) + 三角(耳)
象 = 矩形(底座) + 圆(扁身) + 矩形(颈环) + 圆(主教帽) + 圆(顶球)
后 = 矩形(底/裙环/冠带) + 圆(身/裙) + 三角 ×5(冠尖) + 圆 ×5(冠顶珠)
王 = 矩形(底/颈/颈环/冠带/十字) + 三角(身) + 圆(冠球)
```

**描边怎么来的**：每枚棋子先画一层「整体放大 15.5% 的深色版」，再画本体压上去，
就得到 cburnett 那种「白底黑边」的观感——白棋在浅色格上也看得清。

32 枚全盘约 **480 个图片控件**（每枚最多 15 个图元 × 32 槽）。

## 三、关于 `PREFAB_IMAGE`（**现在是必填**）

v1.3 之后棋子只有图元这一条路，所以**图片控件模板变成必填项**：

> **你需要建一个「图片」控件模板，并把它的模板索引填进 `PREFAB_IMAGE`。**
> 不填的话，脚本启动时会直接报错停下（`PREFAB_IMAGE（棋子用图元绘制，必须建「图片」控件模板）`），
> 因为缺了它棋盘上不会出现任何棋子——报错比让你对着空棋盘猜要好。

这也是删掉圆盘档/符号档的代价：以前「不建图片模板就用纯棋符」这条兜底没有了。
换来的是代码少了一大块、没有任何字体依赖、也不会再出现「棋符显示成方框」的问题。

---

## 四、一句话总结

- **图片编号：一个都不用填**（平台没有棋子图片）
- **图元编号：写死在脚本里**，你不用管
- **你要填的是 4 个「模板索引」**（容器 / 文本框 / 光标检测区域 / 图片），
  那些是「造界面的图纸」编号，不是图片编号——见 `挂载指南.md` 第 3、4 件
