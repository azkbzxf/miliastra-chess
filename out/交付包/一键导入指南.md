# 一键导入指南 · 黑白棋局（v1.11）

> **给你手上这个文件**：`chess-整合包.gia`（250,442 字节，SHA256 `221E16A4…A8B766`）
> **能做什么**：把「客户端控件容器 + 4 个控件模板 + 完整 Lua 脚本源码」一次性导进编辑器。
> **不能做什么**：**联机用的服务端节点图不在里面** —— 节点图是服务端逻辑，
> GIA 格式装不下（原因与做法见第 3 节，只需搭 1 个节点）。
>
> 也就是说：**导入后单机/同屏就能立刻玩；双人联机还需你在编辑器里手动搭一个转发节点。**

---

## ⚠️ 先看这条：`.gil` 和 `.gia` 是两种东西，导入入口完全不同

如果你在**「存档页面」点「导入存档」**，那里**只收 `.gil`**，选不到我这个 `.gia` —— 这是正常的，不是文件坏了。

| 你手上的文件 | 它是什么 | 从哪个入口导入 |
|---|---|---|
| **`.gil`** | **整个关卡的存档**（地形 + 实体 + 节点图 + 界面，全都有） | 存档页面 → 右下角「**导入存档**」 |
| **`.gia`**（我这个） | **单个/组合资产包**（这里是界面控件组 + 控件模板 + 脚本） | 系统菜单 → 「**资产导入导出工具**」→「导入与转存」→「**加载外部资产**」 |

依据（官方文档原文）：
- 《[1.4 存档导入与导出](https://act.mihoyo.com/ys/ugc/tutorial/course/detail/mhjuwpiubrh0)》：
  「最终存档导出文档为【**.gil 格式**的文档】」，导入方式是「存档页面 → 导入存档」
- 《[资产导入导出](https://act.mihoyo.com/ys/ugc/tutorial/detail/mhxbd59urbfu)》第五节：
  「将指定的本地文件夹中的存档文件读取至千星沙箱内的**资产库**页签」，
  入口是「系统菜单 → 资产导入导出工具 → 切到**导入与转存**页签 → 右下角**加载外部资产**」

> **为什么我不能直接给你 `.gil`**：`.gil` 是整关卡存档，需要用编辑器自身序列化
> 整个关卡（含地形、出生点、实体、节点图）。我这边只有 UI 模拟器，
> 它的导出器只产出 `.gia` / `.json` / `.lua`，**没有任何 `.gil` 写手**。
> 伪造一个 `.gil` 会在导入时直接失败，所以我不做这件事。
>
> **但你并不需要 `.gil`** —— 你要的东西（界面 + 棋子 + 脚本）全在 `.gia` 里，
> 按下面第 2 节走「资产导入」就行。

## 1. 这个文件里到底装了什么（先看清，别期待错）

| 内容 | 在不在 | 说明 |
|---|---|---|
| 客户端控件容器（服务端控件） | ✅ 在 | 界面的载体，脚本挂在它下面的容器节点上 |
| 容器节点 | ✅ 在 | 脚本挂载点 |
| 文本框模板 | ✅ 在 | 棋盘格 / 面板 / 按钮 / 坐标全靠它 |
| 光标检测区域模板 | ✅ 在 | 64 格点击检测 + 面板按钮 |
| 图片模板 | ✅ 在 | 拟合棋子图元（100001/100002/100003） |
| **`levelScript.lua` 完整源码** | ✅ 在 | 18.5 万字符，**已内联**，不是路径引用 |
| 脚本与容器节点的挂载关系 | ✅ 在 | 导入后脚本已经挂在容器节点上 |
| **联机转发用的服务端节点图** | ❌ **不在** | 见第 3 节 |
| 关卡地形 / 出生点 / 角色 | ❌ 不在 | 本游戏是纯 2D 界面，不需要地形 |
| 音效资产 | ❌ 不在 | 用的是官方内置音效 ID（`50894` 等），无需导入 |

> **为什么 250KB 而不是几 KB**：早期尝试导出的 7KB GIA 只有脚本的**路径登记**没有源码，
> 导进去会是一个空壳。现在这版把源码真正嵌进去了（可验证：文件里能搜到 `PIECE_ART`、`RULES` 等实际代码）。

## 2. 导入步骤（3 分钟）

### 2.1 导入（**走资产导入，不是存档导入**）

1. 打开「千星沙箱」
2. 系统菜单 → 「**资产导入导出工具**」
3. 切到「**导入与转存**」页签（注意不是「资产库」页签）
4. 点右下角「**加载外部资产**」
5. 在弹出的窗口点「加载外部资产」确认
6. 等待读条 → 出现白字提示「所有文件添加成功」

> 加载前建议先把 `chess-整合包.gia` 放进一个**空文件夹**，然后在那个目录加载 ——
> 这个功能是**读整个文件夹**的，混了别的 `.gia` 会一起导入。

7. 导入后资产会拆成三类，出现在资产库：
   - **UI控件-服务端** ← 客户端控件容器
   - **UI控件-客户端** ← 4 个控件模板
   - **Lua 脚本** ← `levelScript.lua`

8. **右键这些资产 → 「转存资产」**，选一个页签确认 —— 不转存的话它们只在资产库里，
   关卡里用不了（官方第六节「资产使用流程」的要求）

### 2.2 放到场地里

9. 打开「界面控件组管理」→「界面布局」
10. 点「添加界面控件」→ 选中刚转存的**客户端控件容器**
11. 选中它，右侧「画布设置」→「**前往编辑**」→ 确认能看到「容器节点」

### 2.3 核对 4 个索引（**唯一容易踩坑的一步**）

12. 在容器画布里逐个选中控件，读它显示的实际索引：

| 脚本常量 | 应该对应 | 本包内置值 |
|---|---|---|
| `CONTAINER_NODE_INDEX` | 容器节点 | `1073742100` |
| `PREFAB_TEXT_BOX` | 文本框模板 | `1073742106` |
| `PREFAB_CURSOR_AREA` | 光标检测区域模板 | `1073742107` |
| `PREFAB_IMAGE` | 图片模板 | `1073742108` |

13. 打开「客户端脚本资源管理器」→ 双击 `levelScript` → 看文件开头这四行：

```lua
CONTAINER_NODE_INDEX = 1073742100,
PREFAB_TEXT_BOX      = 1073742106,
PREFAB_CURSOR_AREA   = 1073742107,
PREFAB_IMAGE         = 1073742108,
```

**如果导入后编辑器显示的编号和上面一样，什么都不用改，直接跳到 2.4。**
**如果不一样（编辑器重排了索引），把脚本里这四个数字改成你实际看到的。**

> ⚠️ 要填的是「**模板根节点**」的索引，不是模板内部子控件的索引。
> 填错的表现：日志报「界面零件还没配好」，或棋盘有格子但没有棋子。

### 2.4 试玩

14. 保存 → 进关卡试玩
15. 应该看到：棋盘 + 右侧面板；点棋子出现绿点；点绿点能走子

**日志里应出现这几行**（勾选「日志 → 客户端脚本」）：

```
[Chess] 棋子图元：6 种 × 2 方，单枚最多 34 个控件
[Chess] 界面构建完成：控件 1367 个，画布 1600x900，格宽 87.8
[Chess] 启动完成：状态=RUNNING 控件=1367 联机发送=true 接收=true 同屏=false
```

### 2.5 如果导入后什么都没出现

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 「加载外部资产」找不到我的文件 | 文件没放进被加载的那个文件夹 | 单独建个空文件夹放进去 |
| 加载成功但资产库里看不到 | 加载会**清空并替换**资产库 | 先从资产库把以前的转存出来；或直接在「导入与转存」页签看 |
| 资产库有，但关卡里加不了 | 没做「转存资产」 | 右键资产 → 转存资产 → 选页签 |
| 界面出来了但棋子是空的 | `PREFAB_IMAGE` 索引不对 | 见 2.3 |
| 界面完全没出来 | 容器没激活/不可见，或脚本没挂上 | 检查容器状态 + 2.3 的 4 个索引 |

## 3. 双人联机（需要你手动搭 1 个节点）

### 3.1 为什么 GIA 装不下

联机的核心是一个**服务端节点图**：客户端发信号 → 服务端广播给所有人 → 对方客户端收到。
节点图属于**关卡逻辑资产**，不在 GIA（界面控件组 / 控件模板）的表达范围内，
所以必须手动搭。**好消息：只需要 1 个事件节点 + 1 个执行节点，不做任何逻辑判断。**

> 我核实过：模拟器存档里确实带着这条广播规则（`chess-broadcast` / `sendClientScriptSignal`
> / `target: AllPlayers`），但 GIA 导出的字节里**不含这些字段** ——
> GIA 的服务端部分只装 UIControlGroup（界面控件组），不装节点图。

### 3.2 第 1 步：先定义信号（**这步不能跳**）

> 官方规则：信号的参数必须先在「服务器信号管理器」里声明，
> **「发送信号」节点选中信号名后才会长出对应引脚**。不先定义，后面根本接不上。

1. 打开「千星沙箱」→ 新建一张**服务端节点图**
2. 工具栏点「**服务器信号管理器**」→「**添加信号**」
3. 信号名改成 **`ChessSync`**（大小写必须一致）
4. 点「添加参数」**加 5 个参数**，顺序与类型必须完全如下：

| 参数序号 | 类型 | 含义 |
|---|---|---|
| 1 | **整数** | eventType（0=走子 1=新局 2=认输 …） |
| 2 | **整数** | a |
| 3 | **整数** | b |
| 4 | **整数** | c |
| 5 | **字符串** | fen |

5. 点「应用修改」

> ⚠️ **类型一个都不能错**。写成「浮点数」「字符串」都不会报错，但运行时参数对不上，
> 表现为「对方完全没反应」或「收到了但走子无效」——这是最难查的一种错。

### 3.3 第 2 步：搭节点（1 事件 + 1 执行）

```
【事件节点：监听信号】 信号名 = ChessSync
        ↓  （选中信号名后，它会长出 5 个参数输出引脚）
【执行节点：发送客户端脚本信号】
        信号名 = ChessSync
        参数 = 依次接上面监听节点吐出来的那 5 个参数
        目标 = 全部玩家
```

要点（逐条照做，错一个就不通）：

| 项 | 值 | 错了会怎样 |
|---|---|---|
| 监听信号名 | `ChessSync` | 收不到客户端发的信号 |
| 参数引脚 | 5 个**按序**接死，不要漏接 | 漏一个就按默认值（0/空串）走，走子或升变会错 |
| 发送节点 | **发送客户端脚本信号** | 用错节点 → 客户端 Lua 根本收不到 |
| 发送信号名 | `ChessSync` | 客户端 `RegisterServerSignalHandler` 匹配不上 |
| 发送目标 | **全部玩家** | 只回发送者 → 对方收不到 |
| 逻辑 | **原样转发，不做任何校验/存储/排序** | 加判断反而会坏 |

> **两个节点名字很像，别选错**：
> - 「**发送信号**」→ 发给**服务端节点图**（本游戏不用）
> - 「**发送客户端脚本信号**」→ 发给**客户端 Lua**（← **要的是这个**）
>
> 本项目的 Lua 用 `script:RegisterServerSignalHandler("ChessSync", ...)` 监听，
> 对应的是「发送客户端脚本信号」这条链路。

> **引脚的确切名称以你编辑器里显示的为准**：官方文档站没有收录这个节点的完整引脚表，
> 所以上面写的是**语义**（监听端输出的 5 个参数 → 发送端的 5 个参数 → 目标）。
> 如果你的编辑器里目标不是叫「全部玩家」，选任何**"发给房间里每个玩家"**的那个选项即可。
> 判据很简单：**两端都要收到**（发送者自己也会收到，脚本内部做了回声过滤，不用担心重复走子）。

### 3.4 参数含义（想调试时看）

| eventType | 含义 | a | b | c | fen |
|---|---|---|---|---|---|
| 0 | 走子 | 起点格号 0–63 | 终点格号 0–63 | 升变 0=无 1=后 2=车 3=象 4=马 | 空串 |
| 1 | 新局 | 0 | 0 | 0 | 空串 |
| 2 | 认输 | 认输方 0=白 1=黑 | 0 | 0 | 空串 |
| 3 | 求和 | 发起方 | 0 | 0 | 空串 |
| 4 | 同意和棋 | 同意方 | 0 | 0 | 空串 |
| 6 | 身份分配 | 0=你是白方 1=你是黑方 | 0 | 0 | 空串 |
| 7 | 拒绝和棋 | 拒绝方 | 0 | 0 | 空串 |

**格号**：`行号 × 8 + 列号`，行 0 = 最下一排，列 0 = a 列。
所以 `a1=0`、`e2=12`、`e4=28`、`h8=63`。

### 3.5 不搭节点图也能玩

脚本做了能力探测：收不到信号时自动降级成**本地同屏轮流**（两个人共用一台机器轮流点），
面板上会多出「切换本地同屏」按钮。这也是默认状态。

### 3.6 搭好后怎么验

1. 两个人（或两个客户端）进同一个关卡
2. 白方走 e2→e4
3. **黑方屏幕上应该立刻出现白兵在 e4**，轮次变成「轮到黑方走子」，走子记录显示「白 e2→e4」
4. 若黑方没反应：看日志有没有 `已注册联机信号接收：ChessSync`；
   没有就是节点图没生效（信号名/参数顺序/目标三选一错了）

> 官方文档：客户端信号**最低延迟 100ms**，所以联机时对方响应会比单机慢一点点，属正常。

## 4. 已知限制（别当成 bug）

| 现象 | 原因 |
|---|---|
| 面板按钮偶有 1px 级文案裁切 | 极端画布比例下字体度量差异；已在 5 档预设画布验证 |
| 联机时两端棋钟有约 1 秒差异 | 各自本地扣时，不做网络同步 |
| 传送 / 断线重连后界面回到初始状态 | 平台机制：容器隐藏或销毁时客户端控件全部销毁，需自行恢复 |
| 图片控件只显示黑白方块而不是棋子 | 图片模板索引填错，或用了旧版脚本 |

---

## 5. 一句话总结

- **单机 / 同屏**：导入 GIA → 核对 4 个索引 → 直接玩。
- **双人联机**：在上面基础上，再手动搭 1 个「收到即广播」的服务端节点图。
