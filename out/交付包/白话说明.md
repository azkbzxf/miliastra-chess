# 白话说明 · 黑白棋局

> 给你看的这一份，只有四件事。技术细节都在另一份《交付说明》里，你不用看。

---

## 一、这是什么、怎么玩

**这是一个两个人下国际象棋的关卡。** 白方先走，黑方后走。

怎么玩就两步：**点一下自己的棋子，再点一下亮起来的格子**，子就走过去了。

想赢就一个办法：**把对方的王将死**（让对方无路可走）。

---

## 二、你要做什么（按顺序，一步一行）

### 第一步：先玩网页版，确认手感

1. 找到 `chess_demo.html` 这个文件
2. 双击它
3. 等它打开（大概一两秒）
4. 点一枚自己的棋子（比如 e2 的兵）
5. 你会看到几个格子亮成绿色
6. 点其中一个绿色的格子，子就走过去了

玩完告诉我：哪里别扭、快慢合不合适、哪一刻没看懂。

### 第二步：把脚本装进关卡

**先填三个编号**（不填会报「界面零件还没配好」）：

1. 用记事本打开 `levelScript.lua`
2. 找到文件开头的 `CONTAINER_NODE_INDEX = 0`
3. 把那个 `0` 换成你的「容器节点」那串编号
4. 再找到 `PREFAB_TEXT_BOX = 0`，换成你的「文本框」那串编号
5. 再找到 `PREFAB_CURSOR_AREA = 0`，换成你的「光标检测区域」那串编号
6. 保存

**那三串编号在哪拿**：

1. 打开「千星沙箱」
2. 打开「界面控件组管理」
3. 找到你建的那个「客户端控件容器」
4. 点「画布设置」，再点「前往编辑」
5. 选中「容器节点」，点右上角「复制」—— 这是第一串
6. 回到「界面控件组库」，切到「客户端控件模板」
7. 点左下角「添加客户端控件」，选「文本框」，保存 —— 这是第二串
8. 再点一次，选「光标检测区域」，保存 —— 这是第三串

**再把脚本装上去**：

1. 打开「客户端脚本资源管理器」
2. 任选一个文件夹，右键
3. 选「批量添加脚本文件」，再选「按文件」
4. 选中 `levelScript.lua`，点「打开」
5. 看到「添加成功」就好
6. 回到「原神」窗口，打开「界面控件组管理」
7. 找到你那个「客户端控件容器」，点「画布设置」，再点「前往编辑」
8. 选中「容器节点」
9. 在右边切到「脚本」页签
10. 点「添加脚本」，选 `levelScript`
11. 保存
12. 进关卡试一下

### 第三步（可选）：想让两个人各自在自己电脑上下

这一步要你在编辑器里搭一个很小的东西，叫「节点图」。**不搭也能玩**——两位玩家共用一块屏幕轮流点，一样能下完一局。

要搭的话，规则只有一句话：

> 收到一个叫 `ChessSync` 的东西 → 把它原样发给房间里的所有人。

详细步骤在《交付说明》第四节 4.4。

## 三、玩的时候注意什么

| 你可能遇到的问题 | 怎么回事 |
|---|---|
| 点了一枚棋子，没反应 | 可能不是你的回合，或者那枚子走不了 |
| 点了棋子，几个格子变绿 | 绿色 = 这枚子能去的地方，点绿的就行 |
| 自己的王那格变红 | 你被将军了，必须先解围（移王、挡子、或者吃掉对方的子） |
| 弹出一个窗问我选什么 | 你的兵走到对方底线了，要变成后/车/象/马，选一个 |
| 弹窗问我「确定吗」 | 认输、重开、切换模式都会先问你一次，防止手滑 |
| 面板上有两个时间在走 | 那是双方各自的思考时间。轮到谁，谁的时间在减少 |
| 时间变红了 | 那位玩家只剩不到 1 分钟了 |
| 棋盘上的棋子 | 白子白底黑边、黑子深色浅边，六种形状一眼能认出是兵/车/马/象/后/王 |
| 棋盘下面的 a~h、左边的 1~8 | 那是坐标，用来记「这枚子在 e2」 |

## 四、还有什么没做、哪里我还不确定

**没做的**：

- 没有电脑对手（只能两个人下）
- 不能用你自己的棋子图片（平台不允许上传自定义图，原因见下）
- 不能悔棋
- 没有残局练习、没有排位积分
- 不能导出棋谱

**我不确定的**：

- **联机对战我还没在真游戏里试过。** 我这边的资料里没有「服务端」那部分，所以联机只写了一半（另一半要你在编辑器里搭那个节点图）。搭不出来会自动变成同屏轮流，一样能玩。
- **手柄能不能顺手，我没试过。** 键盘鼠标和触屏肯定能用。

**关于棋子长什么样**：

先说结论：**不能用你自己的棋子图片**。千星奇域的图片控件只能用官方预设素材，没有上传入口。我把官方那 1517 个素材全下载看了一遍，里面一个国际象棋棋子都没有（全是箭头、星星、药瓶、音符这类图标）。

所以棋子改用**官方三种基础图元拼**出来的（矩形 `100001` / 圆 `100002` / 三角 `100003`），
拼成 cburnett 那种经典棋形（就是 en-croissant 用的那套）。

**这版为什么只留一种画法**：原来还有「圆盘 + 棋符字符」和「纯棋符」两档备选，
但字符要靠游戏字体渲染，字体里有没有这些字符我没法确认。你说不要了，我就把那两档删了。
现在**完全不依赖任何字体**，形状是自己画的，稳。

每枚棋子先画一层「放大一点的深色版」当描边，再画本体压上去，所以白棋在浅色格上也看得清。

**你不用填任何棋子图片编号。** 三个图元编号（100001/100002/100003）写死在脚本里了。
你要建的是「图片控件**模板**」并把它的**模板索引**填进 `PREFAB_IMAGE`——那是「造图片控件的图纸」的编号，
不是图片素材编号。

**注意：这个现在变成必填了。** 删掉那两档备选之后，棋子只剩图元这一条路，
所以不建图片模板棋盘上不会有任何棋子。脚本会在启动时直接报错提醒你，不会让你对着空棋盘猜。

**字体风险已经彻底没有了**：以前那两档要是字体缺字形会显示成方框，现在不存在这个问题。

**确定能用的**：

- 网页版我实际打开看过、点过、走过子，画面和操作都正常。
- 规则我做了严格验证：易位、吃过路兵、升变、将军、将死、逼和、五十步、三次重复、子力不足，全部和国际标准答案对得上。
- **这版第一次在千星 UI 模拟器里真的下了一步棋**（e2→e4）：棋子会走、轮次会切、记谱对、加秒对、联机信号发出去了。
  这一步以前没做过——之前只在体外沙箱里跑过，而沙箱不会模拟点击，所以「点不动」这类问题测不出来。
  这版就是靠模拟器实跑才发现并修掉了 4 个问题（棋子串格、点击完全失效 ×2、面板按钮点不动）。
- **手机大小的屏幕上也完整**：四种尺寸（1600×900、1280×720、1560×720、1280×960）各打开看过，棋盘、右边面板、四个按钮全部显示完整。
- **图元棋子我在模拟器里截图逐枚看过**：兵/车/马/象/后/王 六种形状都能认出来，白黑分明。

## 一句话总结

**先双击 `chess_demo.html` 玩一局**，觉得顺手了再按第二步装进关卡。装的时候记得先填那三个编号。
