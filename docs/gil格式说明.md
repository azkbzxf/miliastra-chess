内含黑白棋局全部界面 + 5391 行 Lua 脚本源码。

|---|---|
| 文件 | `out/交付包/chess-国际象棋.gil` |

## 为什么不是 .gia

`.gil` 和 `.gia` 是两种东西，导入入口完全不同：

| 格式 | 是什么 | 导入入口 |
|---|---|---|
| `.gil` | **整个关卡的存档**（地形/实体/节点图/界面/脚本） | 存档页面 → 右下角「导入存档」 |
| `.gia` | **单个/组合资产包** | 系统菜单 → 资产导入导出工具 → 导入与转存 |

游戏端「导入存档」的对话框文件类型过滤器写死为 `gil Files`，
选 `.gia` 会被强行追加后缀变成 `xxx.gia.gil` 并产生 0 字节空壳 —— 已实测确认。

## 容器格式（逆向所得，无官方文档）

```
──────── .gil 容器结构 ────────
[4字节 BE] 总长度        = 文件大小 - 4
[4字节 BE] 版本          = 1
[4字节 BE] 魔数          = 0x326     ← 与 .gia 相同，同源
[4字节 BE] 分片数        = 2         ← 第 2 个通常是空尾片
[4字节 BE] 分片0长度
[字节流]   分片0         = protobuf
[4字节 BE] 分片1长度     = 1657（实际无数据）
```

分片0 是 protobuf，46 个顶层字段。与本项目相关的：

| 字段 | 内容 |
|---|---|
| field 1 | 关卡 ID（varint，如 `1073741825`）|
| field 2 | 关卡名（string）|
| field 4 / 5 / 7 | 实体、地形、预设点等 |
| **field 9** | **UI 控件模板**（`field501` 是头部，`field502` 是各模板）|
| field 15 | 背包/环境配置 |
| field 43 | 编辑器版本号（如 `"7.2.0"`）|
| **field 50** | **Lua 脚本列表** |
| field 52 | 关卡 GUID |

### Lua 脚本记录（field 50）

```
field 50 (length-delimited) {
  field 1 (length-delimited) {          ← 外层包装
    field 1 (varint) = 脚本ID           ← 如 1073741826
    field 2 (bytes)  = 脚本名           ← "chessChessProject"
    field 3 (bytes)  = 文件名           ← "chessChessProject.lua"
    field 5 (bytes)  = 源码             ← **明文 UTF-8，可直接替换**
  }
}
```

**源码是明文**，不是编译产物 —— 这是能做到「生成 .gil」的关键。

## 4 个模板索引

脚本通过 `game.InstantiateClientUIControl(prefabIndex, parent)` 在运行时
动态创建全部 1367 个控件，因此只需要 4 个模板索引：

| 脚本常量 | 用途 | 用户存档中的实际值 |
|---|---|---|
| `CONTAINER_NODE_INDEX` | 容器节点（脚本挂载点）| `1073741906` |
| `PREFAB_IMAGE` | 图片（棋子图元）| `1073741867` |
| `PREFAB_TEXT_BOX` | 文本框（棋盘格/面板/按钮）| `1073741868` |
| `PREFAB_CURSOR_AREA` | 光标检测区域（64 格点击）| `1073741869` |

> 索引来自用户导出的模板，不是写死的。换别的存档要重新读。

## 生成流程

```bash
# 1. 用户导出空存档（含 4 个空控件模板）→ chess.gil
# 2. 读取模板索引 + 注入脚本
python tools_work/gil/build.py

# 3. 独立校验（结构/字段/脚本往返）
python tools_work/gil/verify.py
```

`build.py` 做四件事：
1. 解析容器 → 校验「原样重建 == 原 body」（往返测试，必须 True）
2. 读 field 9 找 4 个模板的真实索引
3. 用正则把脚本里 4 个占位符 `0` 替换成真实索引
4. 构造 Script 消息写入 field 50，重算所有 varint 长度 + 容器头部
