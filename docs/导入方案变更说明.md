# 导入方案变更说明

> 2026-11-06。旧《一键导入指南》《挂载指南》合并为《导入方案》。修掉的错误：

1. **「不能给你 .gil」** — 错。该文件已存在（249,929 字节）。旧文把真正的推荐路径写成了否定结论。
2. **「用 .gil 最省事」没说版本** — 它内嵌的是 v1.11 脚本，缺 v1.12 的 `showCursor` 与 `hide_legal_pool`。已补风险专条。
3. **「GIA 装不下节点图」** — 错。官方《资产导入导出》二·1(1) 明列节点图可导出为 `.gia`；是本包没打包。
4. **`PREFAB_IMAGE` 说成图片素材编号** — 应为**图片控件模板索引**（API 参数 `controlPrefabIndex`）。
5. **索引值写死一套** — 那只是模拟器值；同一批模板在 `.gil`、编辑器版、模拟器三处各不相同。
6. **漏 `showCursor` / `raycastTarget`** — 官方 API 文档 24(1)：「CursorEvent 相关方法都需设置该参数为真后才可正常使用」。漏了真机点击全废。
7. **「沙箱 17/17 通过就能玩」** — 错。沙箱无命中测试，交互缺陷测不出。
8. **协议表漏 `EV_JOIN`(5)** — 0–7 已用尽；旧表还把 `fen` 写成「恒为空」。
9. **每枚棋子控件数算错** — 实际 ROOK/QUEEN 各 34 个（17 图元 × 描边+填充两层），不是 17。
10. **报错文案「界面零件还没配好」已不存在** — 实际打 `[Chess] nil` + `CFG_MISSING` 故障块。

新增：三方案分流、30 条故障表、分级验收、附录 A–D、v2.0 待定占位。
