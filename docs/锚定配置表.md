## 一、换算链条（唯一入口）

```
设计基准绝对像素
→ 除以基准画布宽高得到相对值
→ 依据锚点九宫格决定偏移方向与量取起点
→ 依据中心点决定位置从哪一点起算
→ 写入本表，再由表生成赋值
```

**代码里唯一的换算位置**：`lua/levelScript.lua` 第 4 区 `LAYOUT.compute(canvasW, canvasH)`。
除该函数外，代码中不得出现 1600 / 900 / 0.78 / 0.22 这类基准数字（`CONFIG.BASE_CANVAS_H = 900` 用于字号缩放，属同一处集中位置）。

**锚点与中心点约定（本项目统一）**：

| 项 | 值 | 说明 |
|---|---|---|
| 最小锚点 | (0, 0) | 左下角 |
| 最大锚点 | (0, 0) | 与最小锚点相同 → **固定尺寸**，不做拉伸 |
| 中心点 | (0, 0) | 位置从元素左下角起算 |
| 位置语义 | 画布左下角为原点，x 向右、y 向上 | **有父级时的实测结论**，见下方第 30 行说明 |

> **为什么全部用 (0,0) 锚点**：本项目所有元素尺寸都由公式算出（棋盘格 = cell×cell、面板 = 22%×78%），不需要拉伸；统一锚点让「x,y = 左下角坐标」成为唯一语义。

> ### ⚠️ 关于「有父级 / 无父级」——这一节曾经自相矛盾，已按实测更正（2026-11-05）
>
> 旧版这里写的是「无父级时；本项目全部元素直接挂容器节点，**无父级**」。这两句是矛盾的：
> 容器节点本身就是一个父级控件（API 文档 §24）。而 API 文档 §13(3) **L738** 原文是：
> 「`SetAnchoredPosition`：无父层级时，以画布左下为原点设置位置；**存在父层级时，设置与父层级中心的相对偏移**」。
> 若按字面执行，本项目 `x=449,y=99` 会变成「相对容器中心右移 449」，整块界面推出画布。
>
> **实测结论（runtime=simulator，`qxqy_studio_play{action:"get",inspect:true}`）**：
>
> | 采样控件 | 期望（脚本写入的画布坐标） | 运行树读回 `anchoredPositionX/Y` | 判定 |
> |---|---|---|---|
> | `sq_8`（a2，pivot=0） | x=449, y=186.75 | **449, 186.75** | 一致 |
> | `hit_8` | x=449, y=186.75 | **449, 186.75** | 一致 |
> | `legalhl1`（pivot=0.5） | 格中心 = 格左下 + cell/2 | 读回等于格中心 | 一致 |
>
> 即：**父级是容器节点时，`SetAnchoredPosition` 仍然按画布左下为原点解释**，
> 与文档 L738 的「有父级 → 父级中心」分支不符。本项目全部坐标公式按此实现，**保持不动**。
>
> **仍未验证**：以上只是模拟器行为，**真机未验**。真机首测必查项之一就是任取一个控件
> 读回 `GetAnchoredPosition()` 与本文基准值比对；若真机确为「父级中心偏移」，
> 则需改用 `offset = 画布坐标 − 父级中心` 的折算（改动面：工厂 3 处 + 20 处 `SetAnchoredPosition`）。
> 见 `docs/api-audit.md` E-02 的三条路线。

## 二、布局公式（LAYOUT.compute）

```lua
boardSide   = canvasH * 0.78
cell        = boardSide / 8
boardBottom = (canvasH - boardSide) / 2
panelW      = canvasW * 0.22
panelLeft   = canvasW - panelW
panelH      = boardSide
panelBottom = (canvasH - panelH) / 2
-- 水平居中；窄屏降级（仅手机 4:3 触发）
boardLeft   = (canvasW - boardSide) / 2
if (canvasW + boardSide) / 2 > canvasW - panelW then
    boardLeft = (panelLeft - boardSide) / 2
end
-- 字号缩放（v1.11 修正：取宽高较小者，不能只看高度）
fontScale = math.min(canvasW / 1600, canvasH / 900)
-- 实际字号 = floor(基准字号 * fontScale)，下限 16
-- 【为什么取 min】4:3 画布（1280×960）更高但更窄：只按高度缩放会让字号 1.067 倍变大，
--   而面板宽只有 0.80 倍，相对溢出 1.33 倍 → 「切换本地同屏」被截成「切换本地」。
--   min 让已验四档数值逐位不变，只修正原本就错的 4:3。
```
