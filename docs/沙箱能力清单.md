> 来源：`C:\Users\24037\Downloads\MiliastraAgent\release\tools\sandbox\`
> 方法：逐个写探针 Lua 脚本，用 `node run_headless.mjs <脚本> --json` 实测，读 `errors/unsupported/logTail`。
> 用途：**写 Lua 时的硬约束清单**。沙箱没实现的接口，真机可能有、也可能没有；

## 二、**不可用 / 桩 / 与文档不一致**（写代码必须绕开）

| 项 | 实测结论 | 影响与对策 |
|---|---|---|
| **`ServerSignal:AddInt` / `AddString` / `AddParam` 等全部 Add* 方法** | **不存在**！`game.ServerSignal(name)` 返回的表只有 `signalName` 和 `SendSignal` | **致命影响**：沙箱里无法构建带参数信号。对策：代码写成 `if sig.AddInt then sig:AddInt(...) end` 的能力探测 + 降级；沙箱里跳过发送，真机才发。**不能直接调用，否则 OnStart 抛错、verdict=fail** |
| `script:RegisterServerSignalHandler(name, cb)` | 存在但**是空桩**，永远不回调 | 可以调用（不报错），但沙箱里收不到信号 → 联机路径在沙箱**无法验证**，只能验证本地路径 |
| `CursorEventData:GetUIPos()` / `GetPressUIPos()` / `GetUIPosDelta()` | 回调表里**没有这三个方法**，只有 `data.x` / `data.y` / `data.deltaX` / `data.deltaY` / `data.button` | 对策：**不要调用 data:GetUIPos()**（会报 nil 调用）；需要位置就用 `data.x/data.y`。真机上文档说 GetUIPos 存在，但坐标域与布局坐标的关系文档未确认 → 干脆不用坐标，改用「每格一个光标检测区域」的原生命中方案（release 10 §5.3 优先级 1） |
| `Enum.CursorEventType` 取值 | 沙箱自定：`Enter/Exit/Down/Up/Click/BeginDrag/Drag/EndDrag/LongPress`（**没有 CursorClick，是 Click**） | 写代码用 `Enum.CursorEventType.Click`。**注意**：真机文档里叫 `CursorClick`（L435）。沙箱和真机名字不同 → 对策：用一个 CONFIG 里的 `EVENT_CLICK` 常量，取 `Enum.CursorEventType.CursorClick or Enum.CursorEventType.Click`（两边都能取到），避免硬写名字 |
| `Enum.KeyEventType` | 沙箱只有 `Down/Up/LongPress` | 键盘操作路径在沙箱不可验证；本地同屏只用点击，不用键盘 |
| `container.showCursor` 字段 | 沙箱**没有实现**（文档 L926 说 CursorEvent 相关必须先设为真） | 对策：代码里写 `if container.showCursor ~= nil then container.showCursor = true end`，沙箱跳过、真机生效 |
| 控件方法未登记的名字 | **直接报错**并计入 `unsupported`，不是静默忽略 | 对策：只调用本清单第一节里确认可用的方法；不确定的方法先写能力探测 |
| `GetScripts` / `GetScript` / `GetScriptByPath` | 桩，返回空表 / nil | 不要依赖脚本查找做启动就绪判断 |
| `GetItemSize/GetItemSpacing/GetItemIndex/GetPadding/GetContentLength` | 全部返回 0 | 不使用网格视窗控件 |
| `game.GetGlobalCustomVariableValue` | 桩，读不到值返回 nil | 不使用自定义变量做同步（服务端未文档化） |
| `GetText(control)` | 桩，返回空字符串 | 不使用本地化文本映射 |

## 三、判定口径（验收时看这些）

```
verdict          pass / warn / fail —— fail 一律不交付
errors[]         必须为 0
unsupported[]    必须为 0（调了沙箱没实现的 API 会进这里）
controls.neverActivated   必须为 0（建了但没 SetActive(true) 的控件真机不显示）
controls.createdAfterStart / destroyedAfterStart
                 播放期应当为 0（对应「播放期零创建零销毁」）
calls.maxSettersPerFrame  对照性能预算
runtime_verified 恒为 pending —— 沙箱通过 ≠ 真机通过
```

## 四、给 Lua 任务书的硬性约束（由此推出）

1. **棋盘命中不用坐标**：64 个「光标检测区域」控件，每格一个，各自监听 Click → 直接知道点的是哪一格。
   这样绕开「坐标域互不相通」的全部风险（release 10 §5.2）。
2. **所有 ServerSignal 的 Add* 调用必须包在 `if sig.AddInt then ... end` 能力探测里**，否则沙箱 fail。
3. **`Enum.CursorEventType.CursorClick or Enum.CursorEventType.Click`** 取点击事件，两边兼容。
4. **`showCursor` 用 `~= nil` 探测**后再写。
5. **本地同屏模式必须能在沙箱完整跑通**：这是唯一能自动化验证的路径。联机模式在沙箱只能验证「不发信号也不崩」。
6. **启动就绪分三类**（release 10 §3）：配置错误立即报错；对象未就绪有限重试；身份不符立即失败。
7. **逐帧只在必要时开**：棋钟走秒需要逐帧；不用 `OnLevelUpdate`（关卡时停会停表，棋钟不该受时停影响 → 用 `OnUpdate`）。
