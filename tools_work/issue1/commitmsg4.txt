docs: 纠正导入指南的导入入口（.gil 是关卡存档、.gia 是资产包，入口不同）

用户反馈「导入存档只接受 gil 后缀」。核实结论：这不是文件出错，是走错了入口。

## 两种格式的官方定义（已查证）
- `.gil` = **整个关卡的存档**（地形 + 实体 + 节点图 + 界面全都有）
  入口：存档页面 → 右下角「导入存档」
  依据：《1.4 存档导入与导出》「最终存档导出文档为【.gil 格式的文档】」
- `.gia` = **单个/组合资产包**（本次是界面控件组 + 控件模板 + 脚本）
  入口：系统菜单 → 资产导入导出工具 → 导入与转存 → 右下角「加载外部资产」
  依据：《资产导入导出》第五节「本地资产导入/加载流程」

## 为什么不能给 .gil
本项目只有 UI 模拟器（dsh-plugin-beyond-simulator 2.2.2）：
- 导出器可产出的文件扩展名只有 `.gia` / `.json` / `.lua`，**没有任何 .gil 写手**
- 对全部插件文件做过独立词 'gil' 全词搜索：**0 处命中**（miliastra-toolbox 也是 0）
- 插件只认识两种控件资产（client-control-template / server-control-template），
  没有地形、实体摆放、节点图这些 .gil 必须包含的关卡数据

伪造 .gil 会在导入时直接失败，所以不做。用户并不需要 .gil —— 界面+棋子+脚本全在 .gia 里。
