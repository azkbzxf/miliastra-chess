## 0. 本文件怎么用

### 0.1 三类标签的定义（每条用例都必须标）

| 标签 | 含义 | 工具 | 谁能做 |
|---|---|---|---|
| **`[S]` static** | 只读源码即可判定的不变量。答案是确定的、与运行环境无关 | `node tests/static_checks.cjs`（CHECK-9~CHECK-16 为本轮新增）、`node tools_work/lua_check.cjs`、`node tools_work/consistency_check.cjs` | 任何人 |
| **`[M]` simulator** | 必须在千星 UI 模拟器里跑起来才能观测（控件文本/位置/显隐、日志、截图、信号） | `qxqy_studio_play` / `qxqy_studio_play_screenshot` / `qxqy_studio_get` | 仅 Lead（模拟器独占） |
| **`[D]` device** | 只有真机才能得出的证据（点击命中、字体度量、控件容量、跨设备联机、音色） | 用户按 `out/交付包/导入方案.md` 挂载后试玩 | 仅用户 |

**判定纪律（本项目已两条教训换来）**：

1. **模拟器绿灯 ≠ 真机通过。** 凡 `[M]` 通过的项，`[D]` 一栏必须写「未验证」，不许写「已通过」。
2. **一条永远绿的用例不是回归用例 —— 先证明它能红。** 凡新增判据，必须至少给出一条「把实现改回旧写法就会 FAIL」的说明（`Red 现象` 栏）。

### 0.2 每条用例的格式

统一为四段，缺任何一段即视为用例不完整：

```
前置状态 → 操作 → 可观察期望 → 失败边界（Red 现象）
```

- **前置状态**：`GAME.screen` 是什么、走了几步、双方剩余次数、身份如何。
- **操作**：真实指针坐标（模拟器）或控件名（`click {name}`）。
- **可观察期望**：玩家能看到的东西优先（控件 `text` / `active` / 截图），其次日志，最后 `query.*` 诊断。
- **失败边界**：写清「如果实现错了，会看到什么」，用来防止假绿。

### 0.4 坐标重算脚本（改布局后必须重跑，不要手算）

```js
// node -e "<粘贴此段>"
// 【v2.0 校准】按 lua/levelScript.lua 的 START_LAYOUT / LOBBY_LAYOUT 实际值重算：
//   TC_CARDS = { y = 0.400, h = 0.248 }，且 TC_CARDS_X = 0.10 / TC_CARDS_W = 0.80（不是铺满画布）
//   旧值（y=0.455 h=0.190，4 卡铺满）已失效 —— 那版导致「档位名整行不显示」。
const bandY = (y, h) => (y + h / 2) * 900;            // 千星：y 为下边缘比例
const CARD_X = 0.10, CARD_W = 0.80, CARD_GAP = 0.012, CARD_N = 4;
const cardW = (CARD_W - CARD_GAP * (CARD_N - 1)) / CARD_N;   // 0.1910
const cardCX = (i) => 1600 * (CARD_X + (i - 1) * (cardW + CARD_GAP) + cardW / 2);
const start = {
  title:   [800, bandY(0.775, 0.115)],
  sub:     [800, bandY(0.705, 0.052)],
  tcHint:  [800, bandY(0.655, 0.048)],
  cards:   [1,2,3,4].map(i => [cardCX(i).toFixed(1), bandY(0.400, 0.248)]),
  entryR1: [800, bandY(0.175, 0.098)],
  entryR2L:[520, bandY(0.290, 0.098)],
  entryR2R:[1080, bandY(0.290, 0.098)],
};
const lobby = {
  title:   [800, bandY(0.830, 0.085)],
  count:   [800, bandY(0.700, 0.115)],
  roomTc:  [800, bandY(0.625, 0.050)],
  me:      [800, bandY(0.530, 0.080)],
  opp:     [800, bandY(0.440, 0.080)],
  hint:    [800, bandY(0.375, 0.045)],
  ready:   [800, bandY(0.255, 0.098)],
  solo:    [800, bandY(0.150, 0.078)],
};
console.log(JSON.stringify({ start, lobby }, null, 1));
```
